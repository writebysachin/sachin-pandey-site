# SachinPandey.com.np — Design System

## Design Goal
The site should feel like a credible independent consultant/founder site, not an AI SaaS template.
**Desired impression:** Clear → thoughtful → practical → trustworthy → technically capable.

**Avoid:**
- Generic AI gradients
- Excessive glassmorphism
- Futuristic UI for its own sake
- Dashboard-heavy layouts
- Stock-photo-heavy sections
- Excessive animation

## Visual Hierarchy
Problem → Outcome → Evidence → Action

## Color
Use a restrained neutral base:
- **Background:** Warm off-white or dark neutral
- **Primary text:** Near-black / near-white
- **Secondary text:** Muted gray
- **Accent:** One distinctive brand accent
- **Borders:** Subtle neutral
- **Success/error:** Restrained
*(Rule: Do not introduce many accent colors.)*

## Typography
Use one primary sans-serif (e.g., Inter, Plafair Display, Manrope).
- **H1:** Large, strong, short
- **H2:** Clear section statement
- **H3:** Compact supporting heading
- **Body:** Comfortable reading size
- **Small:** Metadata only

## Hero
- **Eyebrow:** B2B GROWTH SYSTEMS
- **H1:** I help B2B companies build marketing systems that compound.
- **Supporting copy:** Websites, SEO, content, and AI workflows designed around the business — not disconnected marketing tactics.
- **Primary CTA:** Get a systems diagnosis
- **Secondary:** Read my work

## Lead Magnet
Make it visually distinct but not aggressive:
- **Header:** FREE RESOURCE
- **Copy:** Find the biggest gaps in your website and SEO system. Enter your website and get a practical diagnostic with the highest-priority areas to investigate.
- **Button:** Get the free diagnostic

## Case Studies
Use: Problem → Approach → Evidence → Outcome.
*(Rule: Only publish outcomes that can be substantiated.)*

## CTA Copy
**Prefer:** Get a systems diagnosis, Get the free diagnostic, Start a conversation.
**Avoid:** Learn More, Submit, Click Here, or repeating "Get Started" everywhere.

## Cards
Use cards only for genuinely grouped information. Do not turn every section into cards.

## Mobile
- No horizontal scrolling
- CTA easy to tap
- Forms simple
- Text readable
- Navigation minimal
- Images optimized
- Cards/sections collapse cleanly

## AI-Generated UI Rule
The coding assistant must not invent new colors, typography, button styles, card styles, or navigation patterns without updating this design system first.
